# Dreamy Demo Vital Sample Pack

Rendered static WAV pack for the Dreamy Demo Vital presets.

Load from Strudel after this directory is pushed to GitHub:

```js
await samples('github:Approximetal/SVLive/main/packages/strudel-dj/samples/dreamy-demo-vital')
```

The sample names match the dynamic `vital()` sound keys:

- `vital_pluck_sad`
- `vital_ch_chill_e_piano_lofi`
- `vital_damped_horn`
- `vital_keystation`
- `vital_lead_3`
- `vital_flute_1`

Render settings: MIDI 36-84, step 4, velocity 0.7, note_dur 1.0s, render_dur 4.0s.
